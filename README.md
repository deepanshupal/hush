# Hush

Local voice-to-text for Mac. Private by default.

## Download
[Hush v0.7.9 for Mac (Apple Silicon)](https://github.com/DeepanshuPal/hush/releases/download/v0.7.9/Hush_0.7.9_aarch64.dmg)

## How it works
Press Fn, speak, release. Your words appear as text wherever your cursor is.

## Features
- On-device AI — nothing leaves your Mac
- Voice Snippets — trigger phrases that expand to full text
- Transcription History — saved locally
- AI Polish — clean up grammar with Groq API (BYOK)
- Per-App Tone — different style per application
