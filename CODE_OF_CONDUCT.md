# Code of conduct

Hush follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not the person. Harassment, insults and personal attacks are not tolerated in issues, discussions, pull requests or anywhere else the project lives.

If someone breaks these rules, report it privately to the maintainer, [@DeepanshuPal](https://github.com/DeepanshuPal). Reports are kept confidential. The maintainer may remove comments, lock threads or block people who don't follow the code.
