# AGENTS.md

Guidance for AI coding assistants (and humans) working in this repository.

## What Hush is

Hush is a free, open-source (MIT) macOS push-to-talk dictation app: hold a key,
speak, and the text is pasted into the frontmost app. Speech recognition runs
locally (transcribe.cpp / ggml with Metal). Optional "AI clean-up" sends the
transcript text to an LLM provider the user configures, with per-app styles.
Built with Tauri 2 (Rust backend, React + TypeScript + Tailwind 4 frontend).

The codebase is derived from an MIT-licensed upstream project. Keep its
copyright line in LICENSE, but don't add upstream branding, links or credits
anywhere user-visible.

We ship macOS only (Apple Silicon DMG). Windows and Linux code paths must keep
compiling, but are not tested or released.

## Commands

```bash
bun install
CMAKE_POLICY_VERSION_MINIMUM=3.5 bun run tauri dev     # run the app
bun run lint && bunx tsc --noEmit                        # frontend checks
bun run check:translations                               # i18n completeness
bun run format                                           # prettier + cargo fmt
cd src-tauri && cargo check && cargo test --lib          # backend
cd src-tauri && cargo test --lib export_bindings -- --ignored   # regenerate src/bindings.ts
```

Release: push a `release-v*` tag (or run the Release workflow) to build the
aarch64 DMG and publish it to `DeepanshuPal/hush-downloads`. CI (`ci.yml`) runs
checks on every push and builds an unpublished DMG artifact on `v1`.

## Architecture

### Backend (`src-tauri/src/`)

- `lib.rs`: Tauri setup, manager initialization, command registration
  (`specta_builder()`), startup model warm-up.
- `actions.rs`: the dictation pipeline: record → transcribe → voice snippets →
  AI clean-up (per-app style, timeout falls back to raw text) → history → paste.
- `app_context.rs`: frontmost app / running apps (bundle id + name only).
- `llm_client.rs`: OpenAI-compatible and Anthropic clients on one shared,
  pooled HTTP client.
- `settings.rs`: `AppSettings` (tauri-plugin-store), defaults, one-time
  migrations (including Hush 0.8 → 1.0), the Hush clean-up prompt.
- `managers/`: audio, model (downloads from Hugging Face), transcription
  (engine supervisor), history (SQLite `history.db`), snippets (same DB).
- `shortcut/`: global shortcuts (`hush_keys` listener on macOS, Tauri plugin
  fallback) and most `change_*_setting` commands.
- `tray.rs`, `overlay.rs`: menu bar icon and the recording overlay window.

### Frontend (`src/`)

- `App.tsx`, `components/Sidebar.tsx`: settings window and sections.
- `components/settings/*`: settings pages (General, Models, AI clean-up,
  Snippets, History, Advanced, About, Debug).
- `overlay/`: the recording overlay window (separate entry point).
- `stores/settingsStore.ts`, `hooks/useSettings.ts`: settings state.
- `bindings.ts`: generated by tauri-specta. Regenerate rather than hand-edit
  when possible.
- `styles/theme.css` + `App.css`: the design tokens (see below).

## Conventions

- **Design tokens.** All colors come from `src/styles/theme.css` (semantic
  `--hush-*` tokens with light and warm-charcoal dark values) registered as
  Tailwind colors in `App.css`: `bg`, `surface`, `surface-raised`, `border`,
  `text`, `text-muted`, `accent`, `accent-contrast`, `danger`, `warning`,
  `success`. Older names (`background`, `mid-gray`, `logo-primary`,
  `background-ui`) are aliases. No hex values in components, no `!important`.
  Fonts: Inter (UI), DM Serif Display Italic (`font-display italic`, headings).
- **i18n.** Every user-visible string goes through i18next; ESLint enforces it.
  Add keys to `en/translation.json` and all other locales
  (`bun run check:translations`). American English.
- **Privacy.** Never log transcript text in release builds (`utils::redact_text`)
  and never log the settings struct or API keys. No telemetry. No network calls
  beyond model downloads and the user's configured AI provider.
- **Persisted data.** The bundle identifier `com.hush.software` and the
  persisted settings values (e.g. the legacy `"handy_keys"`) must keep loading;
  add serde aliases or a migration in `apply_settings_migrations` instead. New
  SQLite tables/columns go at the end of `MIGRATIONS` in `managers/history.rs`.
- **Rust:** `cargo fmt`, `cargo clippy`; avoid `unwrap` on user data paths.
- **Commits:** small and focused; explain why.
